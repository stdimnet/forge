# Getting started

Forge is a PHPStorm-style IDE for Windows, Linux and macOS, built with Rust and Tauri 2. If you
have used PHPStorm, most of what you know carries over: the same layout, the same action names
and the same default keymap. This section takes you from download to a working project.

| Page | What you learn |
| --- | --- |
| [Installation](installation.md) | Install the AppImage, deb/rpm, Windows or macOS bundle, and what the system needs |
| [First start and the Welcome screen](first-start.md) | What you see on the first launch, the Welcome screen, recent projects |
| [Opening and creating projects](projects.md) | Open a folder, the New Project wizard and its generators, the default project directory |
| [Project type detection](project-detection.md) | How Forge recognizes Laravel, Symfony, React, LÖVE & co. and which plugins it activates |
| [Coming from PHPStorm](from-phpstorm.md) | What is the same, what is different, and what is not there yet |

After that, the [user guide](../user/index.md) has one page per feature, and the
[keymap reference](../reference/keymap.md) lists every shortcut.

# Keymap reference card

The 60 shortcuts you need most, PHPStorm's default keymap. Print it or keep it open next to Forge. Every action is implemented; the [shortcut pages](index.md) explain each one, the [keymap reference](../../reference/keymap.md) lists all of them.

| Action | Windows / Linux | macOS | Action | Windows / Linux | macOS |
| --- | --- | --- | --- | --- | --- |
| Search Everywhere | `Double Shift` | `Double Shift` | Select All Occurrences | `Ctrl+Alt+Shift+J` | `Ctrl+Cmd+G` |
| Find Action | `Ctrl+Shift+A` | `Cmd+Shift+A` | Join Lines | `Ctrl+Shift+J` | `Ctrl+Shift+J` |
| Go to Class | `Ctrl+N` | `Cmd+O` | Toggle Case | `Ctrl+Shift+U` | `Cmd+Shift+U` |
| Go to File | `Ctrl+Shift+N` | `Cmd+Shift+O` | Start New Line | `Shift+Enter` | `Shift+Enter` |
| Go to Symbol | `Ctrl+Alt+Shift+N` | `Cmd+Alt+O` | Collapse | `Ctrl+-` | `Cmd+-` |
| Recent Files | `Ctrl+E` | `Cmd+E` | Expand | `Ctrl+=` | `Cmd+=` |
| Switcher | `Ctrl+Tab` | `Ctrl+Tab` | Collapse All | `Ctrl+Shift+-` | `Cmd+Shift+-` |
| Find in Files | `Ctrl+Shift+F` | `Cmd+Shift+F` | Save All | `Ctrl+S` | `Cmd+S` |
| Find in File | `Ctrl+F` | `Cmd+F` | Close Tab | `Ctrl+F4` | `Cmd+W` |
| Replace in File | `Ctrl+R` | `Cmd+R` | Select Next Tab | `Alt+Right` | `Ctrl+Right` |
| Find Next / Move to Next Occurrence | `F3` | `Cmd+G` | Terminal tool window | `Alt+F12` | `Alt+F12` |
| Go to Line/Column | `Ctrl+G` | `Cmd+L` | Settings | `Ctrl+Alt+S` | `Cmd+,` |
| Go to Declaration or Usages | `Ctrl+B` | `Cmd+B` | Hide Active Tool Window | `Shift+Escape` | `Shift+Escape` |
| Back | `Ctrl+Alt+Left` | `Cmd+[` | New Scratch File | `Ctrl+Alt+Shift+Insert` | `Cmd+Shift+N` |
| Forward | `Ctrl+Alt+Right` | `Cmd+]` | Run | `Shift+F10` | `Ctrl+R` |
| Next Highlighted Error | `F2` | `F2` | Debug | `Shift+F9` | `Ctrl+D` |
| Basic Completion | `Ctrl+Space` | `Ctrl+Space` | Run (choose configuration) | `Alt+Shift+F10` | `Ctrl+Alt+R` |
| Parameter Info | `Ctrl+P` | `Cmd+P` | Run Context Configuration | `Ctrl+Shift+F10` | `Ctrl+Shift+R` |
| Generate | `Alt+Insert` | `Cmd+N` | Stop | `Ctrl+F2` | `Cmd+F2` |
| Reformat Code | `Ctrl+Alt+L` | `Cmd+Alt+L` | Rerun | `Ctrl+F5` | `Cmd+R` |
| Comment with Line Comment | `Ctrl+/` | `Cmd+/` | Toggle Line Breakpoint | `Ctrl+F8` | `Cmd+F8` |
| Comment with Block Comment | `Ctrl+Shift+/` | `Cmd+Alt+/` | Step Over | `F8` | `F8` |
| Duplicate Line or Selection | `Ctrl+D` | `Cmd+D` | Step Into | `F7` | `F7` |
| Delete Line | `Ctrl+Y` | `Cmd+Backspace` | Step Out | `Shift+F8` | `Shift+F8` |
| Move Line Up | `Alt+Shift+Up` | `Alt+Shift+Up` | Resume Program | `F9` | `Cmd+Alt+R` |
| Move Line Down | `Alt+Shift+Down` | `Alt+Shift+Down` | Evaluate Expression | `Alt+F8` | `Alt+F8` |
| Move Statement Up | `Ctrl+Shift+Up` | `Cmd+Shift+Up` | Commit | `Ctrl+K` | `Cmd+K` |
| Extend Selection | `Ctrl+W` | `Alt+Up` | Push | `Ctrl+Shift+K` | `Cmd+Shift+K` |
| Shrink Selection | `Ctrl+Shift+W` | `Alt+Down` | Update Project | `Ctrl+T` | `Cmd+T` |
| Add Selection for Next Occurrence | `Alt+J` | `Ctrl+G` | Project tool window | `Alt+1` | `Cmd+1` |

Notation: `Double Shift` means pressing Shift twice quickly. On macOS, `Cmd` is ⌘ and `Alt` is ⌥ (Option).

# Shortcuts by topic

screenshot when it opens something. Actions that are not implemented yet are listed in the
[keymap reference](../../reference/keymap.md) and shown disabled in the
[main menu](../../reference/main-menu/index.md).

## Tips

- **Find Action** (`Ctrl+Shift+A`, macOS `Cmd+Shift+A`) runs any action by name and shows its
  shortcut — the quickest way to learn them.
- In menus and popups the underlined letter (mnemonic) picks an entry.
- Shortcuts use the physical key position, so they work with any keyboard layout.
- Change any shortcut in Settings | Keymap; see [Keymap](../keymap.md).
